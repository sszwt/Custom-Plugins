Compress, resize, and convert Media Library images to WebP. Optional AI smart quality picks the best compression per image.

== Description ==

AI Image Optimization speeds up your WordPress site by reducing image file sizes:

* JPEG / PNG / WebP compression with configurable quality
* Convert uploads to WebP
* Resize oversized images (max width/height)
* Auto-optimize on upload
* Bulk optimize from Media → AI Optimize
* Media Library column with savings %
* Optional AI Smart Quality (Gemini or OpenAI) for content-aware compression

== Installation ==

1. Upload the `ai-image-optimization` folder to `/wp-content/plugins/`
2. Activate the plugin through the Plugins menu
3. Go to Media → AI Optimize to configure settings
