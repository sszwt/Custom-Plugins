Register custom post types & taxonomies, then display them with taxonomy filters and AJAX load more.

== Description ==

* Polished admin dashboard (black / white UI)
* Create unlimited Custom Post Types from the dashboard
* Create taxonomies and attach them as frontend filters
* Shortcode listing with filter chips + Load More (AJAX)
* Display settings: columns, per page, excerpt/image toggles

Shortcode example:

`[cpt_filter_load_more post_type="project" taxonomy="project_category" per_page="6" columns="3"]`

Also available as: `[cptflm ...]`

== Installation ==

1. Upload the `cpt-filter-load-more` folder to `/wp-content/plugins/`
2. Activate **CPT Filter & Load More**
3. Open **CPT Filter** in the admin menu
4. Configure Post Types / Taxonomies / Display
5. Paste a shortcode on any page
