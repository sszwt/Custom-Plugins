# Custom Plugins

Medgrowth WordPress custom plugins (source folders).

## Included

| Plugin | Folder |
|--------|--------|
| AI ACF Block Generator | `ai-acf-block-generator` |
| AI Image Alt Text Generator | `ai-image-alt-text-generator` |
| AI Image Optimization | `ai-image-optimization` |
| Frontend Block Visibility Control | `frontend-block-visibility-control` |

## Install

1. Copy a plugin folder into `wp-content/plugins/`.
2. Activate it under **Plugins** in WordPress admin.

> Advanced Custom Fields Pro is not included (commercial / separate).
